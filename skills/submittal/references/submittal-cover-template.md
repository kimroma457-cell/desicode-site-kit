# 자재승인 요청서 표지 양식

```
                     자 재 승 인 요 청 서

공 사 명 :
현 장 명 :
발 주 처 :
감리(CM) :
시 공 사 :
제 출 일 :  YYYY.MM.DD          제출 번호:  MA-001

| No | 자재명 | 규격 | 제조사 | 사용 위치 | 첨부 서류 | 비고 |
|----|--------|------|--------|-----------|-----------|------|

첨부: 1. 카탈로그  2. 시험성적서  3. 인증서  4. 샘플(별도)

위 자재를 본 공사에 사용하고자 하오니 승인하여 주시기 바랍니다.

                                   시공사:            (인)
                                   현장대리인:        (인)

----------------------------------------------------------
검토 의견 (감리 작성란)
□ 승인   □ 조건부 승인   □ 반려      검토자:        (인)   일자:
```

- 제출 번호는 현장에서 쓰는 체계가 있으면 그것을 따른다.
- 첨부 순서: 표지 → 자재목록표 → 자재별 (카탈로그 → 성적서 → 인증서).
