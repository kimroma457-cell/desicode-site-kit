# 자재승인서 패키지 작성·점검

## 입력
- 자재 목록 또는 내역서
- 업체에서 받은 성적서·인증서·카탈로그 PDF
- `현장정보.md` (현장명, 발주처, 감리/CM, 시공사, 유효기간 기준). 없으면 표지에 필요한 항목만 묻는다

## 진행 순서
1. 자재별 체크리스트 작성
2. 받은 서류를 자재별로 매칭 (file-organizer 스킬과 연계 가능)
3. 누락·문제 표시
4. 승인서 표지 + 자재목록표 작성 — 양식은 `references/submittal-cover-template.md`
5. 업체별 보완 요청 메일 초안 (site-mail 스킬과 연계 가능)

## 자재별 점검표
| 자재명 | 규격·두께 | 제조사 | 사용 위치 | 카탈로그 | 시험성적서 | 발급일 | 유효기간 | 인증(KS·방염·불연 등) | 샘플 | 상태 |

상태 값: 제출 가능 / 보완 필요(사유) / 서류 없음

## 점검 규칙
- **사양 일치**: 성적서의 제품명·규격이 도면/내역서와 같은지. 다르면 두 값을 나란히 적는다
- **유효기간**: 발주처·감리마다 기준이 다르다. `현장정보.md`에 기준이 없으면 '확인 필요 — 감리단 기준 확인'
- **방염·불연 대상 여부**는 판단하지 않고 '확인 필요'로 남긴다
- 시험성적서의 시험기관·발급번호는 원본 그대로 옮긴다
- 서류 원본에 없는 값은 빈칸. 추정 금지

## 출력
1. 결론: 제출 가능 N건 / 보완 필요 N건
2. 자재별 점검표
3. 보완 요청 목록 (업체별로 묶어서)
4. 승인서 표지·목록표 (기본은 문서, 요청 시 docx/xlsx/hwpx)
