# 현장 등록 (키트 시작하기)

목적: 다른 스킬들이 매번 같은 질문을 하지 않도록, 현장 기본정보를 `현장정보.md` 한 파일에 모아 둔다.

## 진행 순서
1. 작업 폴더를 확인한다. 이미 `현장정보.md`가 있으면 내용을 보여주고 수정할 항목만 묻는다.
2. 아래 항목을 한 번에 묻는다 (AskUserQuestion이 있으면 사용, 모르는 항목은 건너뛰게 둔다).
3. 답한 값만 적는다. 모르는 칸은 빈칸으로 둔다. 추정 금지.
4. 사용자가 원하면 기본 폴더 구조를 만든다 (file-organizer 스킬의 구조와 같음).
5. 다음에 할 수 있는 일을 3줄로 안내한다: 공사일보 작성 / 자재승인서 점검 / 도면 검토.

## 현장정보.md 형식
```markdown
# 현장정보
- 현장명:
- 공사명(계약상):
- 현장 주소:
- 공사기간: YYYY.MM.DD ~ YYYY.MM.DD
- 발주처 / 담당자 / 연락처:
- 감리·CM / 담당자 / 연락처:
- 설계사무소 / 담당자:
- 시공사(우리 회사):
- 현장 담당자(작성자) / 직책 / 연락처:
- 메일 서명:
- 주간보고 받는 사람 / 보고 요일:
- 자재승인서 유효기간 기준(감리 기준): 
- 자료 위치: 공정표 파일 / 단가표 파일 / 비율표 파일
```

## 규칙
- 개인 연락처는 사용자가 직접 준 것만 적는다.
- 여러 현장을 운영하면 현장마다 폴더를 나누고 각 폴더에 `현장정보.md`를 둔다.
- 다른 스킬은 작업 전에 `현장정보.md`가 있으면 먼저 읽는다.
