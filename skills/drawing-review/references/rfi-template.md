# 질의서(RFI) 양식

```
                         질   의   서

현 장 명 :                          질의 번호:  RFI-001
수    신 :  (설계사무소 / 감리)       발    신 :  (시공사 / 담당자)
질 의 일 :  YYYY.MM.DD              회신 요청일:  

| No | 관련 도면(번호·명칭) | 위치 | 질의 내용 | 시공사 제안(있을 때만) |
|----|----------------------|------|-----------|------------------------|

첨부: 도면 발췌, 현장 사진 (해당 시)

----------------------------------------------------------
회 신 (설계/감리 작성란)
회신 내용:
회신자:              일자:
```

작성 요령
- 한 질의에는 한 가지 질문만. "A인지 B인지"처럼 답하기 쉬운 형태로 쓴다.
- 시공사 제안은 사용자가 준 의견만 적는다. 없으면 비워 둔다.
- 회신 요청일은 사용자가 정한다. 비워 둔다.
