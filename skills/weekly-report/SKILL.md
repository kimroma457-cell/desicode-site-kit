# 현장 주간 보고서

목적: 한 주간의 자료를 모아 발주처·감리·내부용 주간 보고서 초안을 만든다.

## 원칙
- **자료에 있는 것만 쓴다.** 진행률·인원·수량·날짜를 추정하지 않는다. 없는 값은 빈칸 또는 `[확인 필요]`
- 자료끼리 숫자가 다르면 둘 다 적고 출처를 표시한다
- 보고서는 초안이다. 발송·제출은 사용자가 한다

## 입력 자료 (있는 것만)
- `현장정보.md` (현장명·보고 대상)
- 공사일보 (daily-log 스킬로 만든 것, 또는 엑셀·사진·텍스트)
- 공정표 (엑셀) — 계획 대비 실적 비교용
- 이번 주 현장 메일 (메일 커넥터 연결 시 현장명으로 검색)
- 사용자 메모
자료가 없으면 "현장명과 이번 주 공사일보를 주세요"라고 한 번만 묻는다.

## 보고서 구성
상세 양식은 `references/weekly-report-template.md`를 따른다.
1. 금주 요약 (3줄)
2. 공종별 진행 현황 (계획 대비: 정상 / 지연(사유) / 선행 — 공정표가 있을 때만)
3. 투입 인원 (일자별·공종별, 공사일보 기준)
4. 자재 반입 내역
5. 자재승인·서류 현황 (제출 / 미제출)
6. 이슈 및 협의 사항 (누구와, 무엇을, 결정/미결정)
7. 차주 계획 (공정표 기준)
8. 요청 사항 (발주처·감리에게)

받는 사람에 따라 톤 조절: 발주처·감리용은 격식체, 내부용은 핵심만 짧게.

## 출력
- 기본: 편집·공유 가능한 문서. 사용자가 엑셀·한글 등 형식을 지정하면 그 형식
- 끝에 `[확인 필요]` 항목만 따로 모아 보여준다

## 예약 실행
매주 자동으로 돌리고 싶다고 하면 현장명·자료 위치·요일/시간을 받아 예약 작업으로 등록한다.
