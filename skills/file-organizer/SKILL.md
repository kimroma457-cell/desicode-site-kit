# 현장 서류 정리

목적: 뒤섞인 현장 파일을 정해진 구조로 정리해 필요한 서류를 바로 찾게 한다.

## 안전 규칙 (최우선)
- **원본은 삭제하지 않는다.** 이동·이름변경만 하며, 실행 전에 변경 계획표를 보여주고 승인받는다
- 실행 후 `_정리기록_YYYYMMDD.csv`(원래 경로 → 새 경로)를 남겨 되돌릴 수 있게 한다
- 중복 파일은 지우지 않고 `_중복확인/`으로 모은 뒤 목록을 보여준다
- 판단이 애매한 파일은 `_분류보류/`로 보낸다. 추측으로 분류하지 않는다

## 기본 폴더 구조 (사용자가 다른 구조를 주면 그것을 따름)
```
<현장명>/
  01_도면/
  02_내역·견적/
  03_계약·행정/
  04_자재승인·성적서/
  05_공정·공사일보/
  06_사진/YYYY-MM-DD/
  07_착공·준공서류/
  99_기타/
```

## 파일명 규칙
`YYMMDD_현장명_문서종류_내용_v번호.확장자`
- 날짜는 파일 내용·파일명에서 확인되는 것만 쓴다. 안 되면 수정일을 쓰고 계획표에 `(수정일 기준)` 표시
- 버전이 여러 개면 최신만 본 폴더에, 이전 버전은 `_이전버전/`으로

## 분류 판단
1. 파일명·확장자 (dwg·dxf → 도면, 사진 확장자 → 사진)
2. PDF·엑셀은 첫 페이지/첫 시트를 읽어 판단 ("시험성적서", "자재승인", "내역서", "견적서", "공사일보" 등)
3. 스캔 PDF라 글자가 안 읽히면 이미지로 확인, 그래도 모르면 `_분류보류/`

## 추가 기능 (요청 시)
- **PDF 텍스트 추출**: 같은 이름의 `.txt`를 옆에 저장
- **엑셀 정리**: 병합 셀 풀기, 빈 행 제거, 머리글 한 줄, 숫자 형식 통일. 결과는 `_정리본.xlsx` 새 파일
- **서류 현황표**: 현장별로 있는 서류·없는 서류 표 (자재승인서·성적서 누락 확인용)

## 출력
1. 변경 계획표 (원래 이름 | 새 위치/이름 | 판단 근거) → 승인
2. 실행 결과: 이동 N건 / 보류 N건 / 중복 N건
