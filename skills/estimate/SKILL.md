# 견적서·원가표 계산

목적: 항목 구성과 계산 로직(수량×단가 → 비율 적용 → 소계/합계 → 목표금액 역산)을 매번 같은 방식으로 적용하고, 단가는 항상 파일에서 가져와 틀린 금액이 나오지 않게 한다.

## 필요한 입력 파일
시작 전에 확인한다. 없으면 요청하거나 `resources/`의 빈 템플릿을 복사해 함께 채운다.
1. **단가표** (.xlsx/.csv) — 품목명 / 규격 / 단위 / 단가 / 출처 / 기준일. `resources/단가표_템플릿.csv`
2. **공사유형별 비율표** (.xlsx/.csv) — 공사유형 / 노무비 비율 / 경비 비율 / 기준. `resources/공사유형별_비율표_템플릿.csv`
3. **작업 대상 견적서/원가표** (.xlsx)
`현장정보.md`에 파일 위치가 적혀 있으면 거기서 찾는다.

## 계산 절차
1. **단가 조회**: 항목이 추가되거나 수량이 바뀌면 반드시 단가표에서 품목명(+규격)으로 찾는다.
   - 단가표에 없으면 임의 단가를 쓰지 않는다. 해당 칸은 비워 두고 사용자에게 단가를 묻는다.
   - 사용자가 채팅으로 단가를 지정하면 그 값을 적용하고, 단가표에도 반영할지 묻는다.
2. **재료비**: 수량 × 단가.
3. **비율 적용**: 공사유형을 비율표에서 조회해 노무비·경비를 비율표에 정의된 기준으로 산출한다. 비율표에 값이 비어 있으면 계산하지 않고 묻는다.
4. **소계/합계**: 항목 소계 = 재료비 + 노무비 + 경비. 합계 = 소계의 총합.
5. **목표 금액 역산**: 비율은 유지한 채 합계를 목표 금액에 맞춘다. 어떤 항목을 얼마나 조정했는지 요약에 반드시 적는다. 비율표 자체를 바꿔야 하면 먼저 확인받는다.
6. **서식**: 합계 행은 굵게 + 음영. 기존 시트의 폰트·색·틀 고정 등은 유지한다.

## 결과 보고
- 추가/수정된 항목
- 각 단가를 단가표의 어느 행에서 가져왔는지
- 최종 합계, 목표 금액과의 일치 여부
- 단가표에 없어서 확인이 필요한 품목 목록

## 규칙
- 결과물은 .xlsx로 유지한다.
- 마감된 과거 견적서는 단가표가 바뀌어도 자동 재계산하지 않는다. 요청 시에만.
- 가능하면 숫자 대신 셀 참조 수식을 써서 단가표·비율표가 바뀌면 자동 갱신되게 한다.
- 단가·비율 추측을 결과에 섞지 않는다. 모르면 빈칸 + 질문.

## 예시
입력: "석고보드 9.5T 120㎡ 추가해줘. 인테리어 유형이야."
처리: 단가표에서 '석고보드 9.5T' 조회 → 있으면 재료비 = 120 × 단가 → 비율표 '인테리어' 행으로 노무비·경비 → 행 추가, 소계/합계 갱신.
단가표에 없으면: "석고보드 9.5T 단가가 단가표에 없습니다. ㎡당 단가를 알려주세요. 단가표에도 추가할까요?"
